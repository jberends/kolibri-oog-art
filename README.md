# De kolibrie en het oog

Static site for Jochem Berends’ 2025 charcoal drawing *De kolibrie en het oog* (Sicily). Two pages: the work (`index.html`) and how it was made (`making-of.html`). Photos live in `assets/`.

- Repo: https://github.com/jberends/kolibri-oog-art
- Site: https://jberends.github.io/kolibri-oog-art/ (GitHub Pages, after you enable it on `main` / root)

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000
